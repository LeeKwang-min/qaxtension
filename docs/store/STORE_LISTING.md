## 요약 설명 (Summary / 132자 이내)

> 비개발자도 쉽게 쓰는 웹 QA 도구 — 콘솔·네트워크·성능·접근성 점검과 버그 재현 절차를 한 번에 정리합니다.

*(영문 대안)*
> A simple QA tool for everyone — inspect console, network, performance & accessibility, and capture bug reproduction steps in one panel.

## 상세 설명 (Detailed description)

```
QA Companion은 개발 지식이 없어도 웹 서비스의 품질을 점검할 수 있게 도와주는 사이드 패널 QA 도구입니다.

■ 주요 기능
• 콘솔 로그 수집 — 페이지에서 발생하는 오류·경고를 한눈에
• 네트워크 점검 — 요청 상태·타이밍·실패 응답 확인
• 성능 측정 — 로딩·렌더링 지표 확인
• 접근성 점검 — 대비·라벨 등 기본 a11y 이슈 탐지
• 요소 검사 — DOM 구조, 색상, 요소 속성 확인
• 스토리지 점검 — 쿠키·localStorage·sessionStorage 확인
• 행동 기록 — 클릭·입력을 자동 기록해 버그 재현 절차 생성 (비밀번호는 자동 마스킹)
• 리포트 생성 — 점검 결과를 정리해 복사·공유

■ 개인정보 보호
• 모든 데이터는 브라우저 내부에만 저장됩니다.
• 외부 서버로 데이터를 전송하지 않습니다.
• 비밀번호 입력은 기록 시 자동으로 마스킹됩니다.

QA 담당자, 기획자, 디자이너, 1인 개발자 누구나 부담 없이 사용할 수 있습니다.
```

## 개인정보처리방침 URL

> PRIVACY_POLICY.md를 호스팅한 공개 URL을 입력 (예: `https://<username>.github.io/qaxtension/privacy`)

## 📸 스크린샷 가이드

- **규격**: 1280×800 px (권장) 또는 640×400 px, PNG/JPEG
- **개수**: 최소 1장, **권장 3~5장** (전환율에 직접 영향)
- **촬영 방법**: 실제 사이트에서 사이드 패널을 연 상태로 캡처. 데모용으로 공개 사이트(예: 본인 포트폴리오, 오픈소스 사이트) 사용 권장 — 민감 정보 노출 주의.

### 추천 컷 구성
| # | 화면 | 보여줄 것 |
|---|---|---|
| 1 | 사이드 패널 전체 | 첫인상 — 깔끔한 패널 + 탭 구성 |
| 2 | 콘솔/네트워크 탭 | 실제 점검 결과가 차 있는 모습 |
| 3 | 행동 기록 → 재현 절차 | 핵심 차별 기능 (비밀번호 마스킹 강조) |
| 4 | 접근성/요소 검사 | 점검 범위의 넓이 |
| 5 | 리포트 생성 화면 | 결과물(아웃풋) 강조 |

> 💡 팁: 캡처 후 1280×800 캔버스에 여백/짧은 캡션을 얹으면 전문성이 올라갑니다.
> 캡션 예: "버그 재현 절차 자동 생성", "외부 전송 없는 로컬 점검".

### 기타 선택 자료
